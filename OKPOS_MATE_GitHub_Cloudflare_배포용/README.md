# OKPOS + MATE 시간대별 매출 대시보드

## GitHub 업로드

압축을 푼 뒤 `public` 폴더와 `README.md`를 GitHub 저장소 최상위에 업로드합니다.
`index.html`은 반드시 `public/index.html` 위치에 있어야 합니다.

## Cloudflare Pages 설정

- Framework preset: `None`
- Build command: 비워두기
- Build output directory: `public`
- Root directory: 비워두기

설정을 저장한 뒤 `Retry deployment` 또는 새 배포를 실행합니다.

처음 접속하면 데이터 없이 시작합니다. OKPOS와 같은 매장의 MATE 파일을 함께 선택하면 자동 합산됩니다.
